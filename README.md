# EduMentor AI — بوابة الطالب

تنفيذ للتصميم (Figma) بواجهة عربية RTL: لوحة الطالب، صفحة المقررات وتفاصيل المقرر،
الدليل التفاعلي، المساعد الذكي، سجل النشاط، والشارات — مع Loading State و Empty State
لكل صفحة.

## التشغيل

```bash
npm install
```

```bash
npm run dev
```

ثم افتح <http://localhost:5173>.

| الأمر | الوظيفة |
| --- | --- |
| `npm run dev` | سيرفر التطوير (Vite) |
| `npm run build` | بناء للإنتاج (يشمل typecheck) |
| `npm run typecheck` | فحص الأنواع فقط |
| `npm run preview` | معاينة مخرجات البناء |

## الستاك

- **React 19 + TypeScript** (strict)
- **Vite 8** للبناء والتطوير
- **Tailwind CSS 4** — الثيم مُعرّف كـ tokens في `src/index.css` عبر `@theme`
- **react-router-dom 7** للتنقّل
- **lucide-react** للأيقونات
- **Cairo** خط عربي من Google Fonts

بدون باك-إند: كل البيانات mock في `src/data/`.

### ما هو مشترك بين الصفحات

أي عنصر يظهر في أكثر من صفحة يعيش في `components/ui` أو مجلده الخاص، ويُستورد —
لا يُنسخ:

| المشترك | يستخدمه |
| --- | --- |
| `PageHeader` | المقررات، الشارات |
| `CardGrid` | المقررات، الشارات، الدليل التفاعلي (والسكيلتون في الثلاث) |
| `FilterPills` | فلاتر المقررات، شريط تصفية سجل النشاط على الموبايل |
| `Pill` | `FilterPills` و `StateSwitcher` |
| `TaskRow` | لوحة الطالب، تبويب الواجبات في المقرر |
| `ListRowSkeleton` | المهام القادمة، سجل النشاط، عناصر الوحدات |
| `TextLink` / `TextButton` | روابط "عرض الكل" في أربع صفحات |
| `IconTile` + `tones.ts` | كل الأيقونات الملوّنة في المشروع |
| `Card` / `Section` / `EmptyState` / `ProgressBar` / `StatusBadge` | كل الصفحات |

## الحالات الثلاث للواجهة

`useMockQuery` هي طبقة الجلب الوحيدة، وتعطي `{ data, isLoading }`. الحالة العامة
تُدار في `DataStateProvider`:

- **ready** — تحميل قصير (850ms) ثم البيانات الكاملة.
- **loading** — تُثبّت كل الصفحات على Skeleton (مع `aria-busy` و`sr-only`).
- **empty** — نفس الاستعلامات ترجع بيانات فاضية، فيظهر Empty State المناسب لكل قسم.

للتبديل بينها: الأزرار العائمة أسفل الشاشة (**الحالة: بيانات / تحميل / فاضي**).
هذه الأداة للعرض فقط — في تطبيق حقيقي الحالات تجي من طبقة الـAPI (React Query / SWR)
ويُحذف `StateSwitcher` مع `DataStateProvider`.

Empty State ليس شكلًا واحدًا: كل قسم له رسالته الخاصة (لا إحصائيات / ما بدأت أي مقرر /
لا مهام قادمة / ما نُشرت وحدات / لا نشاط مسجّل...)، ومنها حالات تظهر حتى بوجود بيانات
مثل فلتر لا يطابق شيئًا، أو معرّف مقرر غير موجود.

## Responsive

نقطة الفصل الأساسية `lg` (1024px):

- **ديسكتوب** — سايدبار ثابت على اليمين (264px) + شريط داكن أعلى المحتوى.
- **موبايل/تابلت** — السايدبار يتحوّل درَجًا ينفتح من اليمين بزر القائمة، مع طبقة
  تعتيم، ويُقفل عند اختيار رابط أو الضغط على التعتيم أو بزر Escape.
- الشبكات: الإحصائيات 4 أعمدة ← عمودان، وكروت المقررات والشارات 3 ← 2 ← 1.
- تفاصيل المقرر: عمود الوحدات + عمود المعلومات على الديسكتوب، ويتراكمان على الموبايل.
- **الشريط العلوي** — حقل البحث يتحوّل إلى زر أيقونة، ويظهر زر القائمة.
- **سجل النشاط** — لوحة التصفية الجانبية تتحوّل إلى شريط حبّات أفقي **فوق** السجل
  (لا تنزل أسفل الصفحة)، وصفوف النشاط تنقل الدرجة والوقت تحت النص بدل إخفائهما.
- **مواصلة التعلم** — الزر يصير بعرض كامل تحت العنوان بدل مزاحمته.

قاعدة مهمة اتّبعتها: **لا تُخفى بيانات على الشاشات الصغيرة** — تُعاد ترتيبها فقط.

### فحوصات مطبّقة

كل الصفحات مفحوصة على 320 / 375 / 768 / 1100 / 1440 بصفر `horizontal overflow`،
في حالة التحميل وحالة البيانات. الفخ الذي ظهر وأُصلح: عناصر `grid` ترث
`min-width: auto`، فمحتوى فيه `truncate` أو شريط قابل للتمرير كان يمدّ العمود
ويسبّب تمريرًا أفقيًا للصفحة — العلاج `min-w-0` على عنصر الشبكة.

جميع الاتجاهات مبنية على خصائص منطقية (`start`/`end`, `ms-auto`, `pe-*`) بدل
`left`/`right` حتى يبقى الاتجاه صحيحًا في RTL.

## ملاحظات

- الأرقام والنصوص اللاتينية داخل جمل عربية تُعزل بكلاس `.ltr` حتى لا يعكسها المتصفح.
- الروبوت في بانر الترحيب SVG مكتوب يدويًا — لا صور خارجية في المشروع.
- صفحة المساعد الذكي ترد ردًا جاهزًا واحدًا عبر `cannedReply`؛ لا استدعاء شبكة.
